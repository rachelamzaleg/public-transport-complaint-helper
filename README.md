# עוזר תלונה לתחבורה ציבורית

אפליקציית RTL בעברית להכנת פרטים לפני הגשת תלונה רשמית על תחבורה ציבורית באתר משרד התחבורה.

הכלי אינו מחליף את הטופס הרשמי, אינו מגיש תלונה אוטומטית, ואינו שולח מידע לשרת. כל המידע נשמר מקומית בדפדפן באמצעות `localStorage`.

## מה האפליקציה עושה

- מנתחת תיאור חופשי בעברית.
- מזהה פרטים כמו קו, שעה, תאריך, סוג תקלה ונזק שנגרם.
- מציעה השלמות חכמות לקו, כיוון נסיעה, תחנה וחברה מפעילה.
- יוצרת חבילת הגשה להעתקה לטופס הרשמי.
- פותחת את טופס התלונה הרשמי של משרד התחבורה.

## הרצה מקומית

אפשר לפתוח את `index.html` בדפדפן, או להריץ שרת סטטי:

```bash
python -m http.server 4173
```

ואז לפתוח:

```text
http://127.0.0.1:4173/
```

## פריסה ב-GitHub Pages

הפרויקט הוא אתר סטטי בלבד. לאחר העלאה ל-GitHub:

1. נכנסים ל-Settings.
2. נכנסים ל-Pages.
3. בוחרים Deploy from a branch.
4. בוחרים את branch `main` ואת תיקיית `/root`.
5. שומרים ומקבלים כתובת ציבורית.
